# Черновик DoD команды

**Статус:** черновик v0.2
**Владелец:** Quality & Safety
**Согласовано с командой:** ☐ Product ☐ AI Engineer ☐ Delivery ☐ Quality

Каждый критерий проверяется одним из трёх способов: **есть/нет**, **число**, **ссылка**. Критерий, который нельзя проверить так, в DoD не попадает.

## 1. Общее для всех ролей

| Критерий | Проверка |
|---|---|
| Работа сдана отдельным PR от роли | ссылка на PR |
| Ветка названа `lab1-[role]-initiation` | есть/нет |
| Заголовок PR: `Lab1: [Role] — Initiation Deliverables` | есть/нет |
| CI на PR зелёный | ссылка на прогон |
| Термины в документах совпадают с `docs/glossary.md` | число расхождений = 0 |
| Готова презентация «Я понял проект как…» | ссылка |

## 2. Product / VO

| Артефакт | Критерий | Проверка |
|---|---|---|
| `docs/prd.md` | Назван один сегмент | есть/нет |
| | Болей от 3 до 5, у каждой указано, когда и при чём болит | число 3–5 |
| | North Star задан числом и способом замера, совпадает с `docs/quality/success-criteria.md` | есть/нет |
| | Рядом с North Star — предел задержки (с) и цена запроса (₽) | два числа |
| | PRD прочитан всей командой | число approve = 4 |
| `docs/hypotheses.md` | Гипотез не меньше 3 | число ≥ 3 |
| | У каждой — условие опровержения с порогом | число гипотез без условия = 0 |
| | У каждой — ссылка на боль из PRD | число гипотез без ссылки = 0 |
| `docs/insights.md` | Интервью не меньше 3 | число ≥ 3 |
| | У каждого инсайта — цитата и указание интервью | число инсайтов без цитаты = 0 |
| `docs/glossary.md` | Есть термины «правка», «пункт чек-листа», «версия чек-листа», «согласованный пункт» | есть/нет |
| | Описаны четыре состояния правки: актуальна, отменена, конфликтует, требует уточнения | число состояний = 4 |
| | Для одного понятия один термин («правка» или «требование», не оба) | число синонимов = 0 |
| | У каждого термина — определение и пример | число терминов без примера = 0 |
| | Согласован вслух | отметка в PR от каждой роли, число = 4 |
| `docs/brief.md` | Читается за 2 минуты | число слов ≤ 300 |
| | Есть ссылка на PRD | ссылка |

## 5. Quality & Safety

| Артефакт | Критерий | Проверка |
|---|---|---|
| `docs/quality/success-criteria.md` | У каждого критерия — число и способ подсчёта | число критериев без способа = 0 |
| | У каждой боли из PRD — строка «что значит решает» | число болей без строки = 0 |
| | Целевые значения согласованы с Product | approve от Product |
| | Указано, что меряется автоматически с лабы 3 | есть/нет |
| | Пороги из описания темы перенесены без изменений: recall ≥ 0,85, precision ≥ 0,90, точность состояния ≥ 0,85, главная метрика ≥ 0,80 | четыре числа |
| `docs/quality/golden-dataset-plan.md` | Назван источник для 30–50 пар | есть/нет |
| | Описаны происхождение, версия, формат записи, владелец | есть/нет |
| | Примеров не меньше 10 | число ≥ 10 |
| | Есть примеры с двумя и более порциями сообщений | число ≥ 2 |
| `docs/quality/dod-draft.md` | Каждый критерий — есть/нет, число или ссылка | число непроверяемых = 0 |
| | Согласовано с командой | число approve = 4 |

## 7. Открытые вопросы к команде

- Порог по числу интервью и гипотез (сейчас ≥ 3) — подтвердить с Product.
- Кто, кроме автора, проверяет запуск по README.
- Где хранится отметка «согласовано вслух»: комментарий в PR или отдельный файл.
